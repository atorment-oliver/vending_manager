# Vending Manager

Aplicación de escritorio Windows en C# / .NET 8 para consultar créditos registrados por vending.

## Estado

Proyecto inicial en preparación. La aplicación está diseñada para leer archivos `VendingN.log` sincronizados por Google Drive, mantenerlos intactos y construir una base consolidada local en SQLite. La consulta permite filtrar por fecha y vending, ver créditos procesados correctamente, con error y pendientes, y exportar resultados a CSV.
